🔐 Sign Up & Sign In Page

A modern and responsive Sign Up / Sign In authentication UI built using HTML, CSS, and JavaScript.

The project provides a clean interface for users to create an account and sign in, with basic client-side form validation and an attractive responsive design.

✨ Features

- 🔑 Sign In form
- 📝 Sign Up form
- 👤 Name, email, and password fields
- ✅ Basic form validation using JavaScript
- 📱 Responsive design
- 🎨 Modern UI with smooth transitions
- 🔗 Social login icons
- 🖥️ Works on desktop and mobile devices
- ⚡ No backend required for the current frontend version

🛠️ Technologies Used

- HTML5 — Page structure
- CSS3 — Styling, layout, animations, and responsiveness
- JavaScript — Form validation and interactions
- Font Awesome — Social media icons
- Google Fonts — Custom typography
